# 《仙农洞天：精怪工坊》秘境节气机制差异化设计

## 0. 定位

本文件用于增强秘境探索的辨识度，避免秘境成为“轻战斗 + 掉材料”的外接模块。

秘境应与以下内容绑定：

- 24 节气变化。
- 随行精怪解谜。
- 稀有精怪线索。
- 生态庭院材料。
- 洞天和小镇可见变化。

---

## 1. 设计原则

### 1.1 每个秘境必须有一个节气机制

秘境不是通用地牢换皮，而是被节气规则改变。

示例：

- 惊蛰：雷声唤醒沉睡机关。
- 谷雨：水位周期涨落。
- 小满：资源越采越多，但风险也越高。
- 冬至：光照极短，需要维持灯火链。

### 1.2 精怪是解法的一部分

随行精怪应改变路线、机关、采集方式或风险，而不只是提供战斗数值。

示例：

- 水运精怪开渠。
- 采矿精怪破墙。
- 灯影精照隐藏路。
- 雷竹精稳定雷场。
- 月莲精恢复夜间探索状态。

### 1.3 胜利后改变外部世界

秘境完成后应改变洞天或小镇的一处可见状态：

- 灵渠恢复水流。
- 镇口灯路重新亮起。
- 新商路开放。
- 店铺新增节气顾客。
- 生态庭院新增特殊景观。

---

## 2. 秘境结构

| 层级 | 内容 |
|---|---|
| entry | 进入条件、节气窗口、推荐精怪 |
| field_rule | 水位、雷场、光照、风向等场地机制 |
| puzzle | 精怪解谜点和资源分支 |
| conflict | 小怪、异常天气、风险事件 |
| resolution | Boss、核心采集、外部世界变化 |

---

## 3. 首发 8 个秘境

| 秘境 | 节气机制 | 推荐精怪 | 关键解谜 | 外部变化 |
|---|---|---|---|---|
| 惊蛰雷根洞 | 每 30 秒雷声震动一次 | 雷竹精、灯影精 | 同一次雷声后激活 3 根雷木柱 | 解锁雷竹商路短线 |
| 谷雨回渠境 | 水位每 45 秒涨落 | 月莲精、水运精怪 | 调整 3 个水闸接回主脉 | 洞天灵渠恢复 |
| 立夏虫鸣林 | 虫鸣强弱改变道路 | 花铃精、蜂蜜精 | 按声音节奏选择林道 | 蜂蜜精线索出现 |
| 小满溢谷 | 采集增加满溢风险 | 书契精、采集精怪 | 在收益和撤离之间取舍 | 解锁高产庭院土壤 |
| 白露镜湖 | 倒影显示真实道路 | 月莲精、灯影精 | 根据倒影找到镜莲 | 解锁月莲静池 |
| 寒露霜窖 | 停留越久行动越慢 | 火候精怪、雷竹精 | 在保暖有限时选择路线 | 解锁暖身配方 |
| 霜降残叶冢 | 风向吹开或覆盖道路 | 花铃精、书契精 | 根据落叶判断旧路 | 解锁 NPC 旧物支线 |
| 冬至长灯廊 | 灯灭后道路重组 | 灯影精、月莲精 | 点亮 7 盏灯形成影路 | 镇口灯路常亮 |

---

## 4. 随行精怪解谜能力

| 精怪类型 | 解谜能力 | 限制 |
|---|---|---|
| 水运 | 开渠、渡水、稳定水位 | 每层最多 2 次 |
| 采矿 | 破墙、开矿脉 | 会增加噪音风险 |
| 花香 | 安抚虫群、吸引花蜜虫 | 对机械机关无效 |
| 雷竹 | 稳定雷场、显示雷落点 | 雷雨场景效果最佳 |
| 月莲 | 夜间恢复、稳定倒影 | 白天效果降低 |
| 灯影 | 照隐藏路、维持灯火 | 强光场景效果降低 |
| 书契 | 标记路线、预估风险收益 | 不直接改变地形 |
| 蜂蜜 | 引诱虫群、提升花蜜采集 | 寒冷场景效率降低 |

---

## 5. 奖励结构

| 奖励类型 | 用途 |
|---|---|
| 稀有材料 | 高阶配方、庭院景观 |
| 精怪线索 | 解锁稀有精怪初见 |
| 节气印记 | 年轮试炼和图鉴 |
| 外部变化 | 洞天修复、小镇变化 |
| 店铺机会 | 新顾客、新热卖标签 |
| 远征路线 | 第二年长线派遣 |

秘境不建议只掉装备或铜钱。

---

## 6. 失败补偿

| 失败原因 | 补偿 |
|---|---|
| 战斗失败 | 保留已发现地图和少量材料 |
| 解谜失败 | 获得机关线索，下次提示更明显 |
| 时间耗尽 | 保留节气印记碎片 |
| 精怪状态过低 | 触发精怪照料建议 |
| 满溢值过高 | 下次初始风险降低 |
