# 《仙农洞天：精怪工坊》第二年目标册 UI 与规则设计

## 0. 定位

第二年目标册用于解决主线后“内容很多但玩家不知道先做什么”的问题。它不是额外任务列表，而是把自由游玩整理成玩家能理解、能追踪、能晒图的长期目标系统。

目标册承担 5 个职责：

- 每日推荐 3 到 5 个目标。
- 把精怪、店铺、庭院、远征、试炼、收集串成长期路线。
- 告诉玩家每个目标为什么值得做。
- 降低后期 UI 清单压力。
- 给成就、截图和社区分享提供结构化素材。

---

## 1. 解锁条件

| 条件 | 说明 |
|---|---|
| 主线第四章完成 | 洞天进入稳定期 |
| 第二年春 1 日或通关次日 | 许伯送来旧年鉴 |
| 至少 8 只精怪入队 | 保证目标池足够丰富 |
| 旧铺达到 3 级 | 保证店铺循环已成型 |

---

## 2. UI 入口

| 入口 | 用途 |
|---|---|
| 主菜单：洞天年鉴 | 查看完整目标册 |
| 日终总结：明日建议 | 接收次日推荐 |
| 精怪管理：伙伴目标 | 快速查看羁绊、岗位、心情目标 |
| 店铺结算：名铺目标 | 查看赛季和经营建议 |

---

## 3. 页面结构

```text
┌──────────────────────────────┐
│ 洞天年鉴  第二年 春 3 日        │
├──────────────────────────────┤
│ 今日建议                       │
│ [照料 3 只精怪] [完成 1 单] [修剪灵渠] │
├──────────────────────────────┤
│ 本周目标                       │
│ □ 远征归来 2 次                │
│ □ 触发 1 个伙伴事件             │
│ □ 名铺评分达到 1200             │
├──────────────────────────────┤
│ 本月主题：清明花朝               │
│ 进度 45%  奖励：花铃精线索        │
├──────────────────────────────┤
│ 长期图鉴  精怪 18/48 庭院 5/16   │
└──────────────────────────────┘
```

页面分区：

| 区域 | 功能 |
|---|---|
| 今日建议 | 3 到 5 个短目标，完成时间 5 到 20 分钟 |
| 本周目标 | 2 到 3 个中目标，完成时间 1 到 3 天 |
| 本月主题 | 绑定节气、名铺赛季或年轮试炼 |
| 长期图鉴 | 稀有精怪、庭院、商路、收藏进度 |
| 回忆页 | 展示已完成大目标的小剧场和纪念图 |

---

## 4. 目标类型

| 类型 | 推荐频率 | 设计目的 | 示例 |
|---|---:|---|---|
| daily | 每日 3 个 | 上线就知道做什么 | 照料精怪、补货、完成小订单 |
| weekly | 每周 3 个 | 引导中期规划 | 远征、店铺评级、生态组合 |
| seasonal | 每节气 1 个 | 绑定节气变化 | 清明花朝、冬至灯市 |
| collection | 长期展示 | 提供收集驱动 | 稀有精怪、家具、菜谱 |
| mastery | 长线成长 | 绑定精怪岗位 | 灌溉宗匠、掌柜宗匠 |
| relationship | 情感目标 | 推动 NPC 和精怪事件 | 共居周常、满羁绊事件 |
| challenge | 重复挑战 | 给深度玩家 | 年轮试炼甲等 |

---

## 5. 推荐规则

优先级：

| 优先级 | 条件 | 说明 |
|---|---|---|
| P0 | 节气限定或即将过期 | 防止错过内容 |
| P0 | 精怪心情异常或店铺断货 | 处理负面状态 |
| P1 | 进度超过 60% | 利用完成欲 |
| P1 | 新解锁未体验 | 引导新系统 |
| P2 | 长期收集 | 填充自由目标 |
| P2 | 高难挑战 | 给深度玩家 |

排除规则：

- 地图或建筑未解锁。
- 前置精怪未获得。
- 当日体力和时间明显不足。
- 玩家连续 3 次忽略同类目标。
- 与当前节气冲突。

首页推荐数量：

| 阶段 | 推荐数量 |
|---|---:|
| 第二年开局 1 到 7 天 | 3 |
| 第二年稳定期 | 4 |
| 完成 10 个长期目标后 | 5 |

---

## 6. 奖励结构

| 奖励类型 | 使用场景 | 示例 |
|---|---|---|
| 立即奖励 | 每日目标 | 铜钱、灵息、精怪心情 |
| 解锁奖励 | 周目标 | 新订单池、新庭院装饰、新远征路线 |
| 情感奖励 | 关系目标 | 精怪短事件、NPC 日谈 |
| 展示奖励 | 长期目标 | 年鉴贴纸、称号、庭院纪念碑 |
| 策略奖励 | 挑战目标 | 特殊配方、节气抗性、岗位效率 |

---

## 7. 日终总结联动

| 玩家状态 | 明日建议 |
|---|---|
| 店铺断货 | 明天补充热卖标签商品 |
| 精怪心情下降 | 安排休息或互动 |
| 远征队闲置 | 派出短途远征 |
| 节气试炼临近 | 准备对应属性精怪 |
| 稀有精怪线索出现 | 前往指定地点 |

表现要求：

- 不用红色警告，避免压迫。
- 用许伯批注、精怪贴纸、小镇传闻包装。
- 每条建议显示预计耗时和主要奖励。
