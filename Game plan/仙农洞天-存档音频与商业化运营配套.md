# 《仙农洞天：精怪工坊》存档、音频与商业化运营配套

## 0. 文档定位

这份文档补齐生产配套层：

- 存档字段如何注册、迁移、QA。
- 音频资源如何列清、分组、接入。
- 商业化运营素材如何从开发内容转成持续曝光内容。

---

## 1. 存档生产配套

### 1.1 为什么需要存档注册表

GDD 和存档字段清单能说明“需要保存什么”，但正式开发还需要：

- 字段属于哪个模块
- 字段什么时候加入
- 默认值是什么
- 是否参与迁移
- 是否进入 QA 回归
- 是否允许重算

### 1.2 存档兼容原则

- 所有新增字段必须有默认值。
- 大版本字段变更必须记录 migration。
- 存档读失败时要能定位模块，不应只报“存档损坏”。
- 第二年、精怪羁绊、自由目标等长线内容必须优先纳入兼容测试。

## 2. 音频生产配套

### 2.1 音频分层

| 音频层 | 示例 |
|---|---|
| BGM | 洞天日常、镇上、秘境、终章、宴席 |
| Ambience | 灵田风声、雨声、炉火、店铺人声 |
| SFX | 浇水、收割、加工、开门、结算 |
| UI | 点击、确认、错误、解锁、评级 |
| Spirit | 精怪短叫声、工作声、进化声 |
| Cutscene | 演出专用声效、转场、冲击 |

### 2.2 优先级

P0 音频应优先覆盖：

- 新手前 14 天高频操作
- 第一次精怪成精
- 店铺开门和售卖反馈
- 节气变化
- 终章与结局宴席

---

## 3. 商业化运营素材配套

### 3.1 运营节奏目标

买断制单机也需要持续曝光，但不应做成强运营消耗。

建议节奏：

- 每月 1 篇开发日志
- 每两周 1 条精怪 / NPC / 节气短内容
- Demo 前 6 周进入密集素材期
- Steam 新品节前后集中发布实机内容

### 3.2 素材来源

| 内容源 | 可产出素材 |
|---|---|
| 精怪系统 | 精怪岗位图、进化前后对比、短视频 |
| 店铺经营 | 货架前后对比、顾客反馈、名铺结算 |
| 节气系统 | 节气变化图、天气灾害、年轮试炼 |
| 剧情角色 | NPC 关系图、台词卡、后日谈预告 |
| 第二年内容 | 远征、生态庭院、稀有精怪、隐藏秘境 |
