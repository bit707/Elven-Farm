# 《仙农洞天：精怪工坊》短视频切片执行单

## 0. 目标
为 B 站、抖音、小红书、视频号等渠道准备可批量生产的短视频切片模板。

原则：
- 每条只讲一个卖点
- 15-25 秒内完成起承转合
- 优先展示“看得懂的差异化”

---

## 1. 推荐切片选题

### 切片 01：作物居然会成精
- 时长：15 秒
- 开头钩子：这不是普通种田，萝卜会自己跑出来
- 主要镜头：收成 -> 灵气 -> 成精 -> 跟随

### 切片 02：二十四节气真的影响玩法
- 时长：20 秒
- 开头钩子：惊蛰一到，田里真的会出事
- 主要镜头：节气 UI -> 虫害 -> 防护 -> 收成保住

### 切片 03：精怪自动化帮你开店
- 时长：20 秒
- 开头钩子：它们不是宠物，是你的员工
- 主要镜头：种田 -> 工坊 -> 货架 -> 顾客成交

### 切片 04：从路边摆摊到名铺
- 时长：20 秒
- 开头钩子：一年时间，把破洞天做成整座镇子都离不开的店
- 主要镜头：破铺 -> 开张 -> 名铺陈列 -> 贵客进店

### 切片 05：终章不是单打独斗
- 时长：18 秒
- 开头钩子：最后救回这座镇子的，不只你一个人
- 主要镜头：八位 NPC 集结 -> 大阵启动 -> 终章气氛镜头

### 切片 06：通关后还有第二年
- 时长：20 秒
- 开头钩子：这游戏不是打完主线就结束
- 主要镜头：第二年界面 -> 飞舟商路 -> 同住后日谈 -> 自由造景

---

## 2. 每条切片统一结构
- 0-3 秒：强钩子字幕
- 3-12 秒：卖点核心演示
- 12-18 秒：进一步强化差异点
- 18-20 秒：游戏名 + 愿望单 / 关注 CTA

---

## 3. 制作建议
- 字幕用高对比度大字
- 镜头节奏要快，但不要快到看不清系统
- 不要剪太多纯风景
- 每条都要让观众一眼知道“这游戏特别在哪”
