# 《仙农洞天：精怪工坊》店铺顾客反馈文案与诊断表

## 0. 定位

本文件用于增强店铺经营的可读性。店铺系统已经有顾客标签、定价、货架主题和赛季评分，但玩家必须看懂顾客为什么买或不买，经营才会变成可学习的策略。

目标：

- 顾客进店时表达需求。
- 顾客购买或离开时说明原因。
- 日终总结给 1 到 3 条经营诊断。
- 名铺赛季结算给可执行复盘。

---

## 1. 反馈原则

### 1.1 用自然语言解释系统

不要显示公式：

`price_factor > 1.25`

应该显示：

“有点贵，但如果是送礼的话还可以接受。”

### 1.2 每条负反馈都要暗示改法

| 问题 | 玩家可采取动作 |
|---|---|
| 太贵 | 降价或换目标客群 |
| 不合需求 | 换货架主题或商品标签 |
| 品质不足 | 使用更好原料或精怪加成 |
| 库存不足 | 补充热卖商品 |
| 不合节气 | 查看节气热销标签 |

### 1.3 不用惩罚口吻

差评要像真实顾客表达需求，而不是系统责备玩家。

## 2. 顾客想法泡泡类型

| 类型 | 触发场景 | 例子 |
|---|---|---|
| need_hint | 进店时 | “想买点耐放的路上吃” |
| price_reaction | 看到价格 | “稍贵，但能接受” |
| tag_match | 商品符合需求 | “这个正合今天的用处” |
| tag_mismatch | 不符合需求 | “不是我今天想找的” |
| quality_reaction | 品质高或低 | “品相不错” |
| stock_reaction | 热卖缺货 | “上次那种没有了吗” |
| purchase_reason | 购买后 | “路上带着方便” |
| leave_reason | 离开时 | “我再看看别家” |

## 3. 客群文案

| 客群 | 购买反馈 | 放弃反馈 |
|---|---|---|
| 农户 | “这个价钱踏实，下田前正好吃。” | “好是好，对我来说贵了些。” |
| 镇民 | “正赶上家里要用，来得巧。” | “今天想买点应节的。” |
| 行商 | “耐放就好，远路最怕坏。” | “太占地方，不适合赶路。” |
| 文士 | “这味道清雅，适合夜读。” | “包装若再雅一些就好了。” |
| 富户 | “品相不错，送客有面子。” | “不够稀罕。” |
| 修士 | “灵息很稳，适合调息。” | “属性不合今日修行。” |

## 4. 日终经营诊断

每日打烊后显示 1 到 3 条诊断。

优先级：

1. 明显造成损失的问题。
2. 玩家接近完成的优化机会。
3. 节气或赛季相关建议。

诊断格式：

```text
热卖品断货
今天有 4 位顾客想买暖身类商品，但货架上只剩 1 件。
建议明天补充姜茶、热汤或冬酿类商品。
[查看热卖标签] [去工坊制作]
```

---

## 5. 诊断类型

| 类型 | 触发条件 | 推荐动作 |
|---|---|---|
| price_too_high | 多名顾客因价格离开 | 降价或改卖给富户 |
| price_too_low | 高品质商品低价售出 | 提价 10% 到 20% |
| stock_shortage | 热卖标签商品售罄 | 次日补货 |
| tag_mismatch | 顾客需求与货架不匹配 | 调整货架主题 |
| low_quality | 高要求顾客放弃购买 | 提升加工品质 |
| seasonal_miss | 当前节气热销品缺失 | 查看节气热销 |
| shelf_synergy | 货架组合生效 | 扩展同类陈列 |
| rare_interest | 稀有商品吸引高价值顾客 | 增加礼品包装 |

## 6. 名铺赛季复盘

赛季结算显示 3 到 5 条高层诊断：

| 维度 | 示例 |
|---|---|
| 客群 | “本季最常来的客人是行商，他们偏爱耐放和轻便商品。” |
| 热卖 | “冬酿姜茶贡献了 22% 收入，暖身标签表现稳定。” |
| 流失 | “有 11 位富户因品质不足放弃购买。” |
| 机会 | “如果补充礼品包装，下季富户评分可能明显提升。” |
| 精怪贡献 | “花铃精招呼了 37 位顾客，其中 9 位转化为购买。” |

---

## 7. 新手阶段限制

前 2 小时只开放 3 类反馈：

- 太贵。
- 正合适。
- 想买应节商品。

完成 3 次打烊后再开放：

- 热卖标签。
- 顾客类型。
- 货架主题。
- 定价建议。
