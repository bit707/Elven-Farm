# 《仙农洞天：精怪工坊》UI 页面结构与交互流程

## 0. 文档定位
这份文档用于把 GDD 里的界面描述整理成“可设计、可程序实现、可排交互”的结构稿。

适合谁用：
- UI / UX 设计
- 程序前端 / 客户端
- 主策划
- 新手引导设计

---

## 1. UI 设计原则

### 1.1 视觉方向
- 新中式宣纸、竹木、玉石点缀
- 信息密度高，但不手游化堆叠
- 农场中 HUD 尽量克制
- 菜单中信息完整但层级清晰

### 1.2 操作原则
- 键鼠与手柄完全兼容
- 高频操作不超过两层
- 经营、种植、精怪排班尽量支持一键整理与快速重复

### 1.3 开发原则
- 先做信息架构，再做视觉包装
- 所有高频界面必须先做低保真灰模验证

## 3. 主 HUD

## 3.1 HUD 组成
- 左上：节气时钟盘 + 日期 + 天气
- 右上：灵石、名望、当前提示 Buff
- 角色头顶或脚下：HP / SP / 特殊状态
- 底部中间：快捷栏 10 格
- 右下：任务追踪 1-3 条
- 左下：精怪简要状态提示

## 3.2 HUD 状态切换
### 农场状态
- 强调 SP、时间、天气、快捷栏

### 店铺经营状态
- HUD 简化为营业时间、今日收入、顾客队列提示

### 秘境状态
- HP、SP、随行精怪技能与小地图优先

### 建造状态
- 显示建筑预览、资源缺口、可放置区域

## 3.3 HUD 交互需求
- 鼠标悬停看简要提示
- 手柄切页查看详细状态
- 可在设置中关闭部分非核心 HUD

## 5. 精怪管理页

## 5.1 页面目标
这是全游戏最重要的系统页之一。  
它必须既能看可爱，又能高效排班。

## 5.2 页面结构
### 左侧
- 精怪列表
- 可按岗位 / 五行 / 好感 / 阶段筛选

### 中部
- 当前精怪 3D / 立绘展示
- 当前状态：好感、饱食、干劲、阶段

### 右侧
- 岗位安排
- 技能说明
- 进化条件
- 喂食与互动按钮

## 5.3 关键功能
- 指派岗位
- 切换宿舍
- 查看进化条件
- 更换随行精怪
- 一键喂食
- 一键收礼

## 5.4 高级功能
- 岗位总览模式
- 全农场精怪状态预警
- 组合共鸣提示
- 自动补粮设置

## 5.5 页面开发优先级
### P0
- 精怪列表
- 选中详情
- 岗位切换
- 喂食

### P1
- 共鸣提示
- 进化条件追踪
- 批量管理

### P2
- 详细行为日志
- 精怪关系图

## 11. 节气与天气提示 UI

## 11.1 必须有的提示层级
### 前置提醒
例如“明日惊蛰，虫害风险上升”

### 当日提醒
例如“当前为白露，可采露”

### 结果提醒
例如“因未布防，昨夜冻坏 3 株作物”

## 11.2 提示形式
- HUD 飘字
- 节气转场面板
- 日志记录页
- 图鉴收录提醒

## 12. 新手引导 UI 需求

## 12.1 前 30 分钟必做的引导
- 锄地提示
- 播种提示
- 浇水提示
- 睡觉提示
- 出门去镇上提示
- 第一只精怪互动提示

## 12.2 中期必须弱引导的内容
- 加工收益高于生鲜
- 节气和市闻会改变价格
- 精怪岗位会影响效率

## 12.3 引导原则
- 优先用世界内提示，而不是大段弹窗
- 首次关键系统出现时才用说明面板

## 13. 页面跳转关系

## 13.1 常见跳转
- HUD -> 背包
- HUD -> 快速任务
- 背包物品 -> 上架到店铺
- 精怪页 -> 指派到工坊
- NPC 页 -> 跳转到委托任务
- 图鉴页 -> 查看获取条件
- 工坊总览 -> 单设备加工页

## 13.2 关键闭环跳转
玩家看到某任务需要高品质石斛：
任务页 -> 作物图鉴 -> 石斛详情 -> 合适节气与土壤 -> 精怪管理页 -> 指派药园精怪

这类跳转设计好，用户会觉得系统“串起来了”。

## 15. 当前阶段最该避免的错误
- 先堆装饰风格，不做信息架构
- 把精怪页做得好看但不好排班
- 店铺页只做上架，不做行情反馈
- 建造页没有资源缺口提示
- 任务页和图鉴页无法互跳
